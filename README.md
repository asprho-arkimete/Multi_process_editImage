# Multi_process_editImage
Elabora Multi processi di Editing Imagine  su differenti soggetti e con differenti Lora utilizzando diversi modelli di flux 2 klein 9b/kv, 4b; in oltre esegui Upscale fotogrammi video. e usa location predefinite o personalizzate per creare  le tue foto.  
con preset di prompt per ogni Lora Attigguo.

Istaling:
Clone git clone https://github.com/asprho-arkimete/Multi_process_editImage.git
cd Multi_process_editImage
crea ampiante virtuale python 3.10 -m venv vmulti
cd scripts// vmulti//activate
pip install cuda: pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu130
pip instal -r requirements.txt
scarica cartella lora : https://huggingface.co/Asprho/megalora/tree/main
ed estrai i file rar nella cartella principale,
scarica relise e mettine nella principale cartella:
